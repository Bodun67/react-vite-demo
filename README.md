# React Welcome Demo

Стартовий React-проєкт на Vite з компонентом `Welcome`.

## Запуск

```bash
npm install
npm run dev
```

Компонент `src/components/welcome.jsx` повертає заголовок **Welcome from React**. Файл `src/App.jsx` імпортує компонент і відображає його на сторінці. Стилі заголовка розміщені в `src/App.css`.
